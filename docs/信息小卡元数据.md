# 信息小卡：音频时长与上传者

2026-10-12：为“渺の怪动静”的悬停 / 键盘聚焦信息小卡增加“音频时长”和“上传者”。普通按钮、合集当前成员、彩蛋条目使用同一字段。歌单复用小卡组件，有对应数据时也会显示。

## 字段约定

| SQLite `items` 字段 | 导出的 `Voice.info` 字段 | 类型与显示 |
|---|---|---|
| `info_duration` | `duration` | 可空 REAL，非负秒数，可含小数；显示完整秒，例如 `125.75` → `2:05`，`3665` → `1:01:05` |
| `info_uploader` | `uploader` | 可空 TEXT，上传者显示名；与 `artist` 原唱作者分开保存 |

未填写的字段不显示，也不为旧条目推测上传者。`0` 显示为 `0:00`。时长目前由内容元数据提供，不在悬停时下载或探测本地 / OSS 音频；管理工具以后可以在导入文件时读取实际时长并填入秒数。

两个字段都是可选增量字段，旧数据库仍能只读同步 / 构建；缺少这些列时不会输出新信息。内容同步和构建不会自行升级数据库。

## 升级旧数据库

```powershell
pnpm content:upgrade
pnpm content:sync
```

`content:upgrade` 在数据库旁的 `data/backups/` 创建 SQLite 在线备份，然后在事务内增加缺失字段并更新 `v_items` 视图。保留原记录、排序、路径和 id；失败回滚，可重复执行。新建 / 从 SQL 快照恢复的数据库使用最新 `schema.sql`。

不建议直接用旧版 `schema.sql` 恢复带新字段的 SQL 快照；请把前端代码、schema 和快照作为配套版本使用。

## 录入内容

新增条目可使用两个新参数：

```powershell
pnpm content:add --group noise --zh "新音效" --path "noise/new.mp3" --title "直播片段" --duration 12.5 --uploader "上传者昵称"
pnpm build
pnpm content:verify
```

`--duration` 接受非负秒数，不能填写 `1:23`；该时长应填写 `83`。旧数据库需先升级，省略两个新参数时仍支持原有添加方式。

现有条目可在 SQLite 工具中按 id 更新；先备份，随后同步 / 构建。例如：

```sql
UPDATE items
SET info_duration = 83.25, info_uploader = '上传者昵称'
WHERE id = 具体条目id;
```

上例中的条目 id 需替换为实际数字。不要手改自动生成的 `src/data/content.json` 或 SQL 快照。

## 管理工具接入

当前相邻 WeSingStudio 仓库还没有新字段的编辑界面，本次不修改其代码。现有 Repository 读取 / 更新使用明确的旧字段列表，新增可空列不影响原字段编辑，普通更新会保留新字段；新建记录的两个字段默认为 NULL。

管理工具后续需要：

1. 在 `ItemModel` 增加可空的数值时长与上传者，注意已有 record 构造调用的兼容性。
2. 更新 `ContentRepository` 的 SELECT、INSERT、UPDATE 和 `ModelMapping.ReadItem`；兼容未升级数据库，在明确写入新信息前先执行备份 / 升级。
3. 给编辑页增加秒数输入与上传者输入；时长只接受有限非负数，空值与 `0` 区分。
4. 上传 / 导入阶段可以从媒体元数据获取时长；上传者为显示名，不自动使用 AccessKey、账户凭据或系统用户名。
5. 确保旧字段编辑、数据库备份 / 恢复、配置切换和 SQL 导出均保留这两项。

上传与 OSS 配置的整体对接见 [OSS 与图床管理工具对接](OSS与图床管理工具对接.md)。
