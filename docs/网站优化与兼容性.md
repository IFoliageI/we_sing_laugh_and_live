# 网站优化与内容管理工具兼容性

更新日期：2026-10-09。此记录描述网站第一阶段的修复，不代表已经进行远程部署。

## 1. 不可破坏的约定

| 约定 | 本轮处理 |
|---|---|
| 内容源为 `data/content.db` | 没有更换内容源，没有增删实际内容 |
| `groups / stacks / items / settings / v_items` 的结构、字段与关联 | `data/schema.sql` 逐字节未变，无数据库迁移 |
| 内容管理工具直接读写网站数据库 | 没有改动内容管理工具的源码或配置 |
| `pnpm content:sync`、`pnpm build`、`pnpm dev` | 命令名与正常调用方式保留 |
| JSON 的 `voice / song / groups / secretGroup` 及音频字段 | 生成结构与内容未变 |
| 静态页面 `/`、`/request/`、`/about/` 与 `dist/` 目录 | 路由、静态部署形态和产物目录保留 |
| 音频位于 `public/audio`，缩略图位于 `public` | 路径约定保留，播放时按路径段进行 URL 编码 |

网站仍然是纯静态站点；内容管理工具仍负责内容编辑、构建、本机预览和发布。

## 2. 实施顺序与措施

### 第一项：保护内容

- `content:migrate` 不再从读取生成物的 TS 文件反向导入内容。它现在只在数据库缺失时，从 SQL 快照恢复。
- 现有数据库始终拒绝覆盖；`--force` 被明确拒绝，不会先删除数据库再尝试恢复。
- 恢复先在临时数据库中完成，检查事务与完整性后才创建目标文件。失败不发布半份数据库。
- CLI 添加条目和创建合集使用同一事务，重复路径或写入失败不会留下空的半成品合集。
- `content:rm-examples` 仍然默认只预览，真实删除必须使用独立的 `--yes` 开关。
- 示例清理只删除示例条目和清理后为空的示例合集；包含真实条目的示例合集保留，避免级联误删。
- 网站 CLI 的写入操作先通过 SQLite 在线备份生成 `data/backups/*.db`；备份失败则不写入。
- 快照导出仅接受 `data` 目录中的 `.sql` 文件，不能覆盖数据库、`schema.sql` 或目录外文件。
- 同步及查询使用只读数据库连接；JSON 和 SQL 快照来自同一个读事务。
- 生成物仅在变化时通过同目录临时文件替换，不写出半份文件。

这里的写入前备份只覆盖网站 CLI，不会自动改变桌面工具的数据库写入实现。

### 第二项：修正播放与内容展示

- 媒体生命周期抽出到 `src/lib/audio-player.ts`，进度、暂停、结束和失败都以音频实例识别当前播放。
- 旧音频的迟到事件和失败回调不能覆盖新音频；停止或切换时释放监听与媒体资源。
- 自动播放被浏览器阻止时保留暂停控件，允许用户手动播放；文件或格式错误则清理播放状态。
- 按音频路径和所属分组识别按钮，避免相同显示名称的不同条目一起高亮。
- 空合集保留展示但禁用播放，不再访问不存在的成员。
- 分享链接保留当前页面路径；歌单不会再生成首页分享链接。
- 普通合集成员支持随机播放和分享直链；隐藏音频和彩蛋分组仍不参与默认随机或直链。
- 作者视图包含普通合集成员，并在同作者下合并跨分类重复路径；切换视图时保留播放状态。
- 双击合集保证换到不同成员（成员数大于一时），不再依赖重试随机数。
- 清理提示计时器、合集点击计时器和页面事件监听。

### 第三项：改善交互边界

- 分组标签只定位并展开，重复点击不再折叠刚定位的内容；面板标题仍可折叠。
- 折叠面板、关闭的主题菜单和关闭的导航抽屉不能接收键盘焦点。
- 抽屉支持焦点循环、Escape 关闭和焦点返回；主题菜单支持方向键、Home、End 和 Escape。
- 浏览器存储不可用时，网站的主题切换和导航仍可工作。
- 悬停信息也可通过键盘焦点查看，位置约束在视口中，滚动或缩放时关闭。
- 播放控件兼顾窄屏和安全区域；320px / 375px 下名称与控制按钮分行，不挤压状态文字。
- 长按钮标题、提示和关于页文字可换行；增加可见焦点样式及减少动态效果支持。
- 站点顶栏与页脚读取 `site.ts` 配置。
- 浏览器自动化默认使用 Chrome；开发工具栏关闭，避免它的存储访问干扰隐私模式测试。

## 3. SQL 快照为什么出现差异

`data/content.db` 与 `src/data/content.json` 未被改动。

`data/content-dump.sql` 是同步时自动生成的快照，本轮增强了导出：

- 保存 `items.created_at`，恢复时不再重写原创建时间。
- 保存已有表的 `sqlite_sequence`，恢复后不会复用曾删除的高编号。
- 更新快照头部的恢复说明。

这不是数据库结构变更，也不是内容编辑。旧快照仍能用于恢复，但其中没有记录的历史创建时间无法凭空还原。

## 5. 复验方式

```powershell
pnpm test
pnpm content:sync
pnpm build
pnpm content:verify
pnpm content:check
```

浏览器检查不新增项目依赖；需要已有 Playwright 和 Chrome：

```powershell
# 先启动开发预览
pnpm dev
# 已能解析 playwright 时
pnpm test:browser
# Playwright 在外部工具目录中时，显式指定其路径
pnpm test:browser --playwright <Playwright模块绝对路径> --browser chrome
```

截图保存到被 Git 忽略的 `.checks/`。
检查构建预览时，可指定 `--url http://127.0.0.1:4322 --skip-fixtures`；临时组件注入检查需要开发服务器。

## 6. 后续边界

- 本轮不重做视觉主题、不升级依赖、不引入运行时后端。
- 当前约定是根目录部署；子目录部署不能只修改 Astro 的 `base`，还需要统一导航、字体、图片和播放路径。
- 当前 JSON 约定仍为每栏目一个 `secretGroup`；扩展多个彩蛋分组需要单独讨论兼容方案。
- 将来涉及数据库字段、内容结构或发布协议的变更，需要先说明管理工具影响并获得授权。
- 本轮未自动提交、推送或上线；后续发布前需再次确认真实音档、内容同步与部署目标。
